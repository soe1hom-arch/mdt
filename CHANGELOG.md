# Changelog

## v1.0.0

Initial public release of `mdt`.

### Added

- CLI task manager backed by `TASKS.md`
- Add, list, mark done/undo, remove, and stats commands
- Category grouping and colored terminal output
- Release assets for Linux, macOS, and Windows

### Notes

- `mdt version` reports the embedded release version
- Release binaries are published on the GitHub Releases page
